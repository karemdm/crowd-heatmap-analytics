# Samples

| File | Content |
|---|---|
| `abbey_road_20s.mp4` | 20 s of the Abbey Road zebra crossing in London at night (1920×1080, 30 FPS, no audio): pedestrians crossing and standing on the pavement. |

## Usage

```bash
crowd-heatmap -i samples/abbey_road_20s.mp4 -o outputs/abbey_road_proc.mp4 --no-display
```

## Source

Captured from the public Abbey Road crossing live webcam on YouTube: https://www.youtube.com/watch?v=zMCea32gpmg

People appear in a public space. The clip is included only to demonstrate the tool; if you appear in it and want it
removed, please open an issue.
